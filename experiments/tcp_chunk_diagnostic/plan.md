## 1. 已有证据与待回答问题

- TCP 0.1 候选在新 16 个 development 场景中均于 3–8 步停止，Reach 为 0/16。
- 教师 TCP 标签经同一执行链重放：24/24 完成 88 步，22/24 Reach，与原教师相同长度前缀一致；最大关节修正约 0.01198 rad，最大跟踪残差约 0.00836 rad。
- 前一轮四条拒绝 Chunk 的旋转峰值为 0.0428–0.0744 rad，教师标签峰值约 0.0112 rad；离线去掉旋转后，四条前缀都满足原 0.05 rad 关节步长限制。

这支持执行链能处理已有教师动作分布，尚不能证明所有标签都无误，或唯一确定模型失败原因。教师重放与新场景模型评估不是配对效果比较。

按顺序回答：

1. **拟合问题**：学生在训练来源的教师状态上，能否恢复教师动作的平移、旋转及四步累计目标？
2. **泛化问题**：相同指标在 development 中是否明显变差？
3. **采样问题**：误差是否随 Flow 初始噪声变化，是否集中在某段去噪时间，10→20 步积分是否稳定改善？
4. **执行映射问题**：哪些动作误差对应 IK 无解、关节位置越界或关节步长超限？

不把训练不足、归一化错误或初始化错误预设为结论；本轮也不能单独证明 Memory 的任务收益。

## 3. 实验矩阵与执行顺序

### A. 标签和输入核验：全部 264 窗口，CPU

1. 检查完整分母、split、anchor、时间、Memory 快照和原训练身份。
2. TCP 标签 normalize→denormalize 往返；逐步 compose 后与记录 commanded q 的 FK 目标比较，覆盖完整 16 步。
3. 教师前四步通过只读 IK 检查，分别统计 0.05 / 0.1 rad 下的计划可执行率。

这一阶段复用已有几何与标签工具，只增加与诊断有关的核验。教师前缀异常保留原分母；若发现共同标签、坐标或来源不一致，停止依赖该输入的模型诊断。

### B. 主诊断：全部 264 窗口

| 条件 | 窗口 | 噪声重复数 | Euler 步数 | 输出 Chunk 数 |
|---|---:|---:|---:|---:|
| TCP 学生 | 264 | 3 | 10 | 792 |
| joint-world 参考 | 264 | 1 | 10 | 264 |

重复 0 沿用原开发评估的 `sampling_seed(scene, anchor)`。重复 1、2 使用带版本标签的稳定哈希派生 `(scene, anchor, repeat)`；执行前保存规则和完整 seed 表，不按输出选 seed。

每个窗口 Qwen/Adapter 编码一次，缓存仅在本轮使用，CPU 保存或按轨迹释放，避免保留整批 GPU context。TCP 和 joint-world 共用同一上游 context；各自使用原世界／TCP 相对 Memory 特征。可用性保持原样，不启用额外 dropout。

joint-world 与 TCP 动作空间不同，不比较归一化总 MAE/Flow MSE 排名；只比较各自对教师的误差，以及转换到共同物理空间后的前四步累计 TCP 目标误差和计划可执行性。两组重复数不同，跨组比较只用重复 0。

### C. 采样定位：固定 48 窗口，仅 TCP

固定每条轨迹的 anchor 0 和 80，覆盖起点与末段：32 train / 16 development，共 48 窗口。选样不依赖预测误差或 Memory 是否可用；不能当作全体窗口的随机代表样本。

- **积分分辨率**：在同一初始噪声下，把 B 的 10 步与 20 步比较，3 个重复，共新增 144 个 Chunk。只作诊断，不据此替换默认采样设置。
- **教师路径上的速度预测**：固定 `t={0.1,0.5,0.9}`，对每个窗口使用同一组 3 个噪声，构造 `x_t=tε+(1−t)a`，比较模型 `vθ` 与 `ε−a`；共 432 次单步 Expert 前向。另计算 `â=x_t−t·vθ` 的物理通道误差，作为教师插值路径上的诊断，不等同于自由采样成功率。
- 主采样记录每步去噪状态和最终 clamp 前后数值。优先对现有 Euler 函数加局部只读观测包装，不修改核心积分公式；固定首个 train 和 development 场景各三个 anchor，检查包装路径与原采样结果一致。

按 A→B→C 执行；B 在轨迹间交替处理 train/development。资源不足时保留计划分母和未运行项，不缩小分母声称完成。C 不触发追加训练或自适应扩大样本。

## 4. 指标、计算与分母

**主读数：TCP 学生前四步的平移误差、旋转误差，以及全部四步均可通过 IK/位置/步长检查的窗口比例。** 每个噪声重复都保留，不能选最好的样本。

| 层次 | 指标 |
|---|---|
| 单步动作 | xyz 分量偏差和三维误差范数（mm）；旋转分量偏差（rad）及旋转矩阵间 geodesic 角误差（degree）；夹爪单独报告 |
| Chunk 结构 | slot 0、slots 1–3、slots 4–15 分开；前四步逐步累计位置／姿态目标误差，以及完整 16 步辅助读数 |
| 输出幅度 | 教师与学生各通道 p50/p90/max、非有限值、最终 clamp 比例、clamp 前超界幅度；同时保存原始夹爪预测和执行时固定打开的事实 |
| 随机性 | 每窗口三个采样结果的误差分布、四步累计目标分散程度和可执行结果一致性 |
| Flow | 三个固定 t 的分通道速度残差与 clean-action 估计误差；自由采样去噪状态随步数变化 |
| 运动学 | 前四步 IK/FK 回代、关节位置限制、最大计划关节增量；在 0.05 / 0.1 rad 下分别统计全前缀通过率和首个失败位置／原因 |

累计目标误差使用双方从同一 actual TCP 起点组合出的 SE(3) 目标比较。joint-world 先累计其 commanded q，再经 FK 进入共同 TCP 空间。不把关节表示的总误差和 TCP 表示的总误差直接相除。

IK 调用纯运动学接口，不调用 executor 的真实发送路径；不构造“完美跟踪”的伪控制器来冒充实际跟踪测试。IK 失败与位置越界保留；只在有有效解的前缀统计关节步长大小，并同时报告完整可执行率分母。

“离线计划可执行”不等于 PD 在 50 ms 内可跟踪，不计算或声称真实 tracking pass、Reach 成功率或闭环净收益。

分层：train/development、Memory available/unavailable、早／中／晚 anchor；按轨迹先汇总，再展示跨轨迹分布，避免把同一轨迹的窗口／噪声重复当作独立场景。保留每层样本数。接近零的教师旋转不使用不稳定的相对百分比误差。

0.05 / 0.1 rad 是既有执行合同，作为可执行性界限；本轮不临时发明动作精度 promotion 阈值。其他指标报告连续效应与逐轨迹方向，不事后改主指标。

## 5. 结果怎样影响下一步

| 观察 | 可支持的判断 | 下一步建议，另行形成变更方案 |
|---|---|---|
| 教师标签重构／参考 IK 已异常 | 输入、标签或运动学前提存在问题 | 先定位异常，不用训练掩盖 |
| train 状态也有明显动作误差／大量计划不可执行 | 已见状态的拟合或采样仍有问题 | 查尺度、输出头迁移、训练覆盖与优化；不能直接归因于泛化 |
| train 明显好于 development | 存在泛化差距的迹象 | 查数据与状态覆盖；窗口相关性保留 |
| 教师插值路径速度残差大，20 步也未改善 | 单纯增加积分步数缺乏收益证据 | 优先查模型拟合；不能唯一认定训练步数不足 |
| 相同噪声下 20 步稳定改善，或不同噪声波动很大 | 数值积分／生成分布值得进一步检查 | 再设计采样设置对照，不直接替换策略 |
| 平移较准，旋转误差与 IK 超限同时突出 | 旋转输出是优先排查通道 | 设计旋转尺度／监督／姿态保持的单因素实验 |
| 同教师状态离线表现良好，历史 rollout 仍提前停止 | 教师状态诊断不足以解释闭环失败 | 下一阶段核对 policy-induced 状态与控制响应 |

教师动作只是该教师策略的参考，不是唯一正确动作；有动作误差不自动等于任务失败。Memory 分层存在相关性，不构成 Memory 因果收益证明。

## 6. 资源、停止与交付

建议使用已有单卡串行执行：**GPU 进程累计上限 15 分钟、CPU 运动学与核算累计上限 15 分钟、峰值显存不超过 24 GB、新增产物及临时缓存总计不超过 512 MB**。既有权重／数据不复制，不下载依赖或购买资源。若需要恢复／传输或现有资源不可用，先报告实际缺口，不能视为已获运行授权。

这是本诊断建议预算；不假定前轮剩余 GPU 时间自动授权新实验。获准执行后，所有阶段与最多一次实现／环境修复共享总预算。重试只补未完成或协议无效的计算，不按结果重抽噪声。预计规模：1,200 个完整学生 Chunk，其中 B 为 1,056、C 新增 144；另 432 次速度预测前向。CPU IK 可流式按前缀处理，超时即停止并记录覆盖率。
