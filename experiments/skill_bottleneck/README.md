## 研究问题与数据流

验证当前视野不足时历史 Memory 是否改善动作，以及当前测量与 Memory 都不可用时，
按真实证据触发的重观察是否比固定观察时机更有效。最终看技能与任务收益，不只看 loss。

```text
真实双图、proprio、相机位姿与时间
  → 合格 G2C 测量 → Memory 写入 / 更新 / 失效
  → 每次重规划生成不可变快照
  → 冻结 Qwen 视觉语言 context + Memory Encoder token
  → 共享 Action Expert → 执行前4步 → 下一次真实观测

当前测量与 Memory 连续不可用
  → 证据规则提出重观察请求
  → Supervisor 检查阶段、接触、控制归属与尝试预算
  → 暂停 / 清理旧动作 → 真实相机路线 → 候选测量
  → 返回 HOME、建立4帧新历史 → 提交 Memory
  → 新快照 / 重规划 / 继续执行
```

首版请求来自连续真实观测的可用性规则，不新增 learned observation head，不声称冻结
Qwen 学会了观察决策。重复调用同一帧不算连续控制 tick。模型和 Memory 不直接控制相机。

## 复用与必要缺口

复用正式 G2C/校准包、D049 提交、暂停/HOME/重规划链路，以及
`experiments/memory_conditioning/` 的 Snapshot、Encoder 和 Policy。
上一轮只有4个 train样本、1个合格 development样本、32步离线训练，未见额外收益；
没有训练后的 Memory 策略动态闭环证据。该小试权重不作为本轮共同初始化。

- 从同一已恢复 V1 Layer12 checkpoint 初始化。首批冻结 Qwen 和 Adapter，训练 Expert，
  Memory 条件另训练 Encoder；保持双图、15D proprio、16×8 commanded-target、
  20Hz/执行前4步及已有 Flow 语义，不同时改变 Adapter 解冻等因素。
- 补候选 checkpoint 的严格身份验证和 Runtime 消费；不能靠忽略新增参数通过旧 loader。
  保存模型、Encoder、特征配置、归一化身份和训练恢复状态。
- 每次重规划按实际时间和状态取新快照，一次 Flow 求解共用该快照；执行阶段仍检查接触、
  运动与失效。快照不可变不等于动作持续获准。
- 工程探针已将仿真 RETURN 从40步改为10步：消费开始年龄由2.2s变为0.7s，TTL仍为2.5s。
  这只验证可用窗口，不是任务成功率证据。仿真时间与墙钟分别记录，不改时间戳或静默放宽有效期。
  Memory失效后按用户选择清旧动作、以新画面和masked Memory重规划，继续剩余技能。
- 当前控制器硬限制每 Episode 一次主动尝试，初始化主动观察也计入预算。先验证一次运行中
  请求的完整闭环；初始化观察加后续刷新需明确候选生命周期及总尝试数，不能重建 controller
  清零计数。重复观察协议尚未确定，不把现有接口说成已支持无限刷新。
- 当前静态 Object Memory 仅覆盖抓取前；接触、关闭夹爪或物体运动会使其失效。
  首批五技能任务衡量抓前收益的传递。抓持物体状态、目标位置 Memory 是后续覆盖
  lift/transport/place 所需的独立设计，不能沿用抓前位置，尚未实现或验收。

## 数据与对照

D0 的176条完整五技能 train轨迹作为动作回放基础，不能当作动态 Memory 监督。
新开发采集记录真实观测历史、pose/time、Memory 来源及读写/失效、观察与暂停恢复事件，
保留 commanded-target 标签、边界窗口和失败。GT 只用于教师标签或明确的隔离诊断，
不能补造可部署 Memory 输入。原子技能的专家准备状态不等于可用 Memory：必须实际
产生观测历史，否则使用不可用掩码。

数据覆盖当前可见、过去可见但当前不足、当前与 Memory 均无效、重观察成功及失败。
遮挡与视角处理必须和测量一致，不能只遮 Qwen 输入却让 provider 偷看未遮挡图。
D0/新数据比例、技能与事件曝光、Memory dropout、预算在训练前固定。
只用 train 和新 development，不重新消费历史 val/confirmation/final test。

| 执行条件 | Memory | 主动观察 | 目的 |
|---|---|---|---|
| 视觉对照 | 屏蔽 | 无 | 衡量整个信息补充机制的净收益 |
| Memory＋固定观察 | 合格快照 | 预定时机 | 观察时机对照 |
| Memory＋证据触发观察 | 合格快照 | 信息不足时请求 | 检验按需观察的收益与成本 |

两个观察条件共享 Memory checkpoint、路线和尝试上限。有/无 Memory 训练方法比较
固定共同上游初始化、数据和优化预算，分别保存训练所得权重。另以同一 Memory checkpoint
和实际观测前缀作 token 开/关诊断，位置打乱只作离线反例；不混淆训练对照与推理消融。
当前 D049 返回 HOME 后主要经 Memory 消费新信息；没有明确消费者的“仅重观察”条件
不是有效信息对照。上述三组不是完整2×2因果分解。当前固定三帧HOME前缀、预定或HOME score候选门控、
3:1旧/新数据及新development seeds；完整参数与证据见 memory_reobserve/README.md。
当前触发规则只在起始三帧上评估，不声称Qwen已学会任意时刻的主动观察。

## 执行顺序与验收

1. 接通候选 Runtime、规划快照和新鲜证据触发，验证时效、暂停清理、HOME提交与继续执行；
   验证关闭候选后基线路径一致，不先启动普通五技能续训。
2. 在新预算内采集信息缺失和恢复过程，核对标签、时间、来源与完整分母。
3. 训练无 Memory 和有 Memory 条件，保留共同初始化、恢复状态及预定检查点。
   不拆成五个独立动作网络，不按开发结果任意追加训练或只挑最好的技能。
4. 原子技能→相邻组合→完整五技能任务评估。组合只在起点由专家准备，交接不 reset、
   不补专家动作；同 scene seed 不代表不同策略具有逐动作配对的随机性。

报告每技能成功/总数、组合条件与无条件成功、完整任务成功及未到达技能；条件分母为0
时记不可估计。额外报告 Memory 年龄、可用率、来源和失效原因，测量到消费延迟，
请求/批准/拒绝/观察成功数及成本，更新后实际动作与任务收益。抓前、抓后覆盖分别说明。
保留教师准备失败、模型失败和协议错误，不替换失败 seed 凑成功率。
