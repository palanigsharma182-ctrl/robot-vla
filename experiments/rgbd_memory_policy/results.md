# 第二阶段：RGB-D Memory进入训练与仿真执行

2026-09-07。**工程消费已验证，任务性能没有正信号。** 新采集24个场景，完成两臂各256次参数更新及三条件各4场景闭环执行。Memory真实参与了训练，并驱动104个实际仿真动作，其中64个发生在front遮挡期间；但三个条件均未达到2cm接近阈值。代码位于main工作区的独立实验目录，稳定src与第一阶段实现保持原样。

这是已知4cm立方体、静止运动学无碰撞目标、夹爪打开的抓前接近development实验。不是任意物体几何认证、完整抓取、五技能验收或物理闭环，也不是canonical默认策略晋升。协议及完整脱敏分母见[README](README.md)、[protocol.py](protocol.py)和[summary.json](summary.json)。

## 实际数据流

同一真实仿真时刻的front RGB-D、K、相机位姿和时间 → 第一阶段三平面位置估计 → Memory有效性检查和不可变快照 → 同帧双图/proprio与快照绑定 → 冻结Qwen视觉上下文 + 12维Memory encoder产生的一个token → Action Expert → 16×8 commanded-target增量chunk → 现有执行器每次执行前4步 → 每一步重新读取传感器并更新Memory。

12维包括base-frame XYZ、协方差上三角6维、年龄、置信度和当前可见标记。没有合格Memory时屏蔽token，不用GT填补。教师与结果距离计算可读取GT；学生几何和策略输入不使用GT位置。教师标签来自实际发送命令相对于上一command target的增量。Qwen上下文取第12层，Qwen和Adapter均冻结，训练更新Expert及Memory臂的encoder。

每场景执行预定HOME→第二视角→HOME的真实hold观察；此后逐步读取固定相机的新画面。没有学到的视角选择。Memory到期后中断原chunk，用新画面重新规划并继续；这次学生rollout没有覆盖到“到期后重新获得合格Memory”，不能把末段首次获取误称为重新获取。

## 数据与训练证据

| 指标 | Train | Development |
|---|---:|---:|
| 完整场景 | 16/16 | 8/8 |
| 16步标签窗口 | 176 | 88 |
| 有效Memory窗口 | 57（32.4%） | 26（29.5%） |
| 有效Memory场景 | 12/16 | 5/8 |
| 经历过期的场景 | 7 | 3 |
| 过期后再次有效的场景 | 3 | 2 |

所有24个教师场景均执行96步并到达2cm内。上述重新获取发生于教师采集轨迹，不能替代学生执行的证据。无Memory和过期样本均保留，没有按测量成功挑选或替换场景。

两臂相同上游权重、采样顺序、Flow噪声、学习率及256更新预算；每次更新累计2个样本，Memory有25%预定dropout。Memory臂512次样本消费中实际有141次token-on（27.5%），覆盖50个唯一窗口、12个有Memory的train场景；120次更新出现encoder非零梯度，encoder参数变化L2为0.0167369。Visual臂对应的Memory曝光、梯度、参数变化均为零。两份checkpoint均由严格身份校验加载，重载后的固定噪声development结果一致；保存的是推理checkpoint，不含Adam恢复状态。

同一Memory checkpoint在88个development窗口上的FlowMSE：开启0.0066251419，屏蔽0.0066250926；有效Memory的26个窗口也基本持平（开启0.0056448968、屏蔽0.0056447300）。因此loss下降证明本轮训练拟合了教师标签，不能当成Memory带来的收益。

## 三条件实际闭环

4个新的预定development rollout seed，三条件实际初始图像/proprio/目标状态/Memory均配对核验。每场景88动作、22次规划；12/12完成，执行异常0。Reach判定为每次chunk执行结束的距离检查中是否达到2cm，未宣称连续时间全轨迹检测。

| 条件 | Reach | 平均初始距离 | 平均最终距离 | 使用Memory动作 | 遮挡期Memory动作 | 真实视觉回退 |
|---|---:|---:|---:|---:|---:|---:|
| Visual训练权重 | 0/4 | 11.02cm | 17.88cm | 0 | 0 | 0 |
| Memory训练权重，开启Memory | 0/4 | 11.02cm | 17.71cm | 104 | 64 | 2 |
| 同一Memory权重，屏蔽Memory | 0/4 | 11.02cm | 17.85cm | 0 | 0 | 0 |

同权重开启Memory的平均最终距离仅改善1.409mm；逐seed改善约3.582mm、2.032mm、0、0.022mm。没有Memory可用的场景，两种同权重条件最终距离完全相同。**全部12个执行单元的最终距离均大于初始距离**，说明当前策略尚未学成有效的闭环接近行为。4个场景和全零成功率不能支持显著收益或把失败归因于Memory本身。

两次Memory失效都发生了真实的后续视觉规划与执行，不能仅用中断计数代替回退。学生rollout中到期后重新获取Memory为0；第四场景末段的8个Memory动作来自首次获取。front遮挡期间wrist可能仍能看见目标，不把这项消费证据称作完全失明任务成功。

## 事后只读XYZ诊断

主实验结束后，为区分“存在一个Memory token”和“XYZ数值影响动作”，新增独立脚本[diagnose_consumption.py](diagnose_consumption.py)。未追加训练或执行动作；复用相同checkpoint和原collection，严格核验二者身份。固定全部8个development场景分母，取5个有合格Memory场景的首个可用anchor，3个不可用场景明确保留。协议在预测前保存，不按结果选样。此项是事后诊断，不冒充主实验预定指标。

固定图像、proprio、采样噪声，保持其他9维和可用mask不变，只改XYZ；另测移除token。全部5个样本重复原输入均bitwise相同。

| 扰动 | 前4步、7关节指令差的RMS范围（rad） |
|---|---:|
| X增加10cm | 0.0000144–0.0000250 |
| Z增加10cm | 0.0000119–0.0000187 |
| XYZ归零 | 0.0000133–0.0000205 |
| 屏蔽Memory token | 0.0000156–0.0000264 |

XYZ对输出有可复现的数值影响，但很弱。这里测量的是反归一化后的关节命令增量差，并非机械臂实际位移；采用原BF16推理路径，不能排除量化对微小差值的影响，也未证明方向正确或数值变化具有实际控制意义。

## 判断与后续研究边界

本轮已经排除了“Memory完全没接入训练或执行”这一解释。当前证据指向两个仍需区分的问题：有效Memory曝光不足（训练仅27.5% token-on），以及当前单token条件方式没有学出足够强且正确的空间控制响应。所有条件均远离目标，也提示需要优先排查训练标签拟合到闭环执行之间的差距，不能只加Memory数据或只归因于Qwen。

建议下一项有界对照先检验同一几何转换为target−TCP相对位置后对接近控制的作用，并与现有教师位置伺服比较；同时核验首个动作方向、执行后距离变化和joint command reference。该建议尚未实现或运行，不因本轮完成而自动启动新的训练。
