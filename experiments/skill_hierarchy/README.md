# 完整任务 → 三个操作 → 七个细技能

当前训练交付与局限见 [七阶段 BC 结果](bc_results.md)。本目录保留实际执行的研究代码；`overnight.py` 存在已确认的阶段末尾平台窗口问题，不能依赖其自动判断收敛或切入完整任务。完整任务 runner 已实现并做单元测试，但本轮没有执行学生完整闭环；入口/出口与扰动范围仍是候选合同。

2026-09-08：用户明确同意本层级，并要求同时制定可容许误差范围。层级与职责采用如下定义；数值是首版候选合同，教师名义场景通过也不等于学生已具备对应容错能力。

| 操作 | 细技能 | 负责的行为 | 完成结果 |
|---|---|---|---|
| Pick | Approach 接近 | 从初始位置接近物体上方的预抓取区域，保持开爪 | 进入粗接近区域 |
| Pick | Align 对齐 | 在预抓取区域完成位置、接近姿态和速度调整 | 可开始最后接近与抓取 |
| Pick | Grasp 抓取 | 最后约 5cm 接近、闭爪、形成短时稳定抓持 | 当前持物，相对夹爪位姿短窗口稳定 |
| Pick | Lift 提起 | 保持抓持，脱离支撑并上升 | 进入可搬运高度区间 |
| Carry | Transport 搬运 | 保持抓持与足够离地高度，移动到目标上方 | 进入下降入口 |
| Place | Lower 下降 | 保持抓持，下降并完成近目标位置、速度调整 | 可开始释放 |
| Place | Release 释放 | 开爪、等待、检查物体稳定落置 | 沿用完整任务的物体最终位置和稳定判据 |

这是两级行为分解，加上完整任务可称三层。三个粗操作不是三个同级细技能，也不要求训练七个网络。当前共享 BC 的输入和架构不变；此实现提供教师分段与独立起点评估语义，尚不是学生可调用的 skill-conditioned policy。

## 数值合同

可执行单一来源为 `contract.py` 的 `ENTRY`、`EXIT` 和 `PERTURBATIONS`。单位使用米、秒、度；边界包含等号。平移/速度均为向量模长，不能逐轴同时取最大值。下表是便于阅读的摘要，完整的抓持、开口、支撑力条件以代码为准。

| 细技能 | 允许接手的入口范围 | 判定完成的范围 |
|---|---|---|
| Approach | 未持物；实际可达、无碰撞的任务初始状态分布，无统一球形位置界限 | 距预抓取点 ≤40mm，TCP 速度 ≤0.20m/s，归一化实际开口 ≥0.9 |
| Align | 距预抓取点 ≤60mm，速度 ≤0.25m/s，开口 ≥0.8 | 位置 ≤8mm，等价抓取姿态角误差 ≤5°，速度 ≤0.08m/s，开口 ≥0.9 |
| Grasp | 距预抓取点 ≤20mm，姿态 ≤10°，速度 ≤0.15m/s，开口 ≥0.8，尚未持物 | 真实抓持，连续三个观测点的相对位姿变化 ≤2mm/5°，速度 ≤0.08m/s |
| Lift | 当前稳定抓持，速度 ≤0.15m/s | 物体中心相对桌面静置中心抬升 80–160mm，支撑接触力 ≤0.1N，保持抓持，速度 ≤0.20m/s |
| Transport | 当前稳定抓持，抬升 60–180mm，速度 ≤0.25m/s | 目标 XY 误差 ≤15mm，抬升 80–160mm，保持抓持，速度 ≤0.12m/s |
| Lower | 当前稳定抓持，目标 XY 误差 ≤30mm，抬升 60–180mm，速度 ≤0.15m/s | XY ≤10mm，相对目标中心 z 偏差 −2…+8mm，保持抓持，速度 ≤0.04m/s |
| Release | 当前稳定抓持，XY ≤20mm，z 偏差 −3…+12mm，速度 ≤0.08m/s | 已发送开爪命令、当前未持物、目标三维距离 ≤25mm、物体速度 ≤0.01m/s、角速度 ≤0.5rad/s，连续四帧 |

“当前稳定抓持”仅是三点、0.10 秒的相对位姿窗口证据，不是力闭合或抗扰能力认证。夹爪开口取两个手指关节位置平均值除以 0.04m，不把它称为精确指垫间距。支撑力 0.1N 是数值接触容差，未经实机标定。Release 的物体结果阈值保持原任务语义，额外显式检查释放命令确实执行。

Align 的目标姿态在 episode 开始由教师固定，按当前方块的 90° 等价抓取方向计算误差；不能随着当前 TCP 姿态重新定义目标。抓持后的滑移比较不折叠 90° 对称。当前任务不要求最终物体朝向，因此没有凭空给 Transport/Release 加绝对世界姿态目标；它们的姿态变化须保持真实抓持并在可达路径内。

入口集有意比前一出口集宽：前一出口落入后一入口，但两者不要求相等，更不要求两段使用同一精确姿态。正常交接允许位置、姿态和速度偏差；丢失抓持、单侧接触不能解释成正常误差，应单列恢复问题。历史事件保留用于诊断，实时 `grasp_lost` 可中止 Lift/Transport/Lower。

## 待测扰动幅度

| 变量 | 常规档 | 挑战档 | 压力档 |
|---|---:|---:|---:|
| TCP 平移偏移模长 | 5mm | 10mm | 20mm |
| yaw 偏差 | 5° | 10° | 20° |
| roll/pitch 合成倾斜 | 3° | 5° | 10° |
| TCP 线速度增量模长 | 0.02m/s | 0.05m/s | 0.10m/s |
| TCP 角速度增量模长 | 5°/s | 15°/s | 30°/s |
| 持物相对夹爪抓取偏位 | 1mm / 2° | 2mm / 5° | 4mm / 10° |

这些是采样幅度，不是成功阈值或已验证的允许误差。扰动后的实际状态仍须检验所属入口集；若超出，记录为越界压力测试，不混进正常容错分母。速度是围绕真实交接速度的增量，不能强行把入口静止化。抓取偏位用真实接近、接触、闭爪与运动生成，不瞬移持物，不修改抓持 bool。先单因素正负方向，再混合扰动和学生真实交接状态；8–12 场景初筛只能定位失效区域。

## 实现与兼容边界

- `contract.py`：层级、入口/出口范围、实时不变量、相对抓持窗口、候选扰动配置。
- `probe.py`：复用可信教师，七段各自在首次达到上述出口时停止。分段采集与独立准备共用 `run_until(stop_before)`；最后完成动作归前一技能，下一动作归后一技能。
- `test_contract.py`：边界包含关系、阈值与缺失值、累计滑移、抓持丢失、重复帧、释放稳定窗口等反例。
- 探针独立 sidecar 使用新版本和 `fine_skill_id`，含 before/after 状态、动作序号及命令目标。canonical `TrajectoryArrays.skill_id` 仍为旧五技能；探针未将新 ID 写入旧数据集。
- 仿真物体/目标位姿、抓持与接触仅用于教师及 privileged 评估，不送入学生输入。旧 32 条数据缺少物体姿态，不能伪造七技能相对姿态稳定标签；后续新采集需保存对应 sidecar。
- 探针使用新的 development seeds 1800000–1800003；四条完整轨迹，加 seed 1800000 的 Grasp/Lower/Release 独立准备，共七单元，上限 4200 动作。没有自动启动新 BC 训练或扰动扫描。

执行结果与已发现的协议问题见 `results.md`。旧五技能训练和评估结果不因此改名或重新解释。
