# 指标驱动 BC：A/B 训练与反馈结果

2026-09-08，`metric-bc-v2`；最终执行状态更新于2026-09-09。**A/B 各完成 1,024 次更新和四轮反馈评估；固定最终权重在反馈开发组上的结果不支持 B 优于 A，也没有显示稳定闭环收敛。** 保留开发组评估已因288次episode上限停止，完成143/144单元，B缺一个单元及其离线指标，不能称为完整最终比较。

方案见 [recovery_bc_plan.md](recovery_bc_plan.md)，机器可读聚合证据与源码哈希见 [metric_bc_feedback.json](metric_bc_feedback.json)。本文使用完整反馈轮次，不根据进行中的保留评估调整结论、采样或模型选择。

## 实验条件

- A 为固定七技能均衡采样；B 按任务失败和分组离线指标调整既有训练数据的曝光。
- 两组从第七阶段同一父权重、优化器及随机状态开始；各1,024次更新，每次累积7个训练窗口，各曝光7,168个窗口（含重复），不是新增7,168条轨迹。
- 训练数据为124条合格轨迹、21,706个窗口；共享Expert、冻结Qwen/Adapter/Memory、Memory masked、AdamW学习率1e-5、BF16保持一致。两组训练均采用math SDPA和确定性算法。
- 前256次更新采样相同，实际Expert权重digest相等，首轮闭环聚合结果一致；此后B才按反馈改变分布。
- 固定反馈开发场景为1811000–1811007。F从真实reset初态开始；S由教师只完成Approach后交接。每个轮次为8个场景×2种起点，共16个完整单元。
- 学生连续执行完整Pick→Carry→Place；七技能指标只用于旁路诊断，不因Align候选条件未通过而截断。选择固定1,024更新权重，不挑中途最好结果。
- 1811008–1811031为最终比较的保留开发场景，训练期间不用于本轮采样反馈；这些场景参与过历史离线监控，不能称为未见final test。

## 固定最终权重：完整任务没有稳定改善

| 指标 | 原权重 | A：固定采样 | B：指标驱动采样 |
|---|---:|---:|---:|
| F完整任务成功 | 0/8 | 0/8 | 0/8 |
| S完整任务成功 | 0/8 | 1/8 | 0/8 |
| F曾达到短时稳定抓持 | 0/8 | 0/8 | 1/8 |
| S曾达到短时稳定抓持 | 8/8 | 5/8 | 8/8 |
| F执行错误 | 3/8 | 2/8 | 4/8 |
| S执行错误 | 5/8 | 0/8 | 1/8 |

短时稳定抓持只要求三个观测、约0.10秒的物体与夹爪相对位姿稳定，不能解释为可靠抓取、抗扰能力或后续任务已完成。B在S入口的8/8短时抓持没有转化成完整任务成功；A最终只有S入口的一个场景成功。执行错误包括实际TCP/IK或执行约束失败，保留在计划分母中，不作为实现异常删掉。

## 数据分布确实改变，但没有表现出完整任务收益

本轮获得额外采样的桶是 **Approach-exit**（Approach出口附近窗口，group 2）。

| 用于哪段训练 | Approach-exit实际采样概率 |
|---|---:|
| 前256更新：与A配对 | 3.82% |
| 257–512更新：首轮反馈后 | 8.82% |
| 513–768更新：第二轮反馈后 | 13.44% |
| 769–1,024更新：第三轮反馈后 | 13.44% |

每轮实际概率变化遵守5个百分点上限，单技能和事件额外配额也受约束。基础分布随focus混合进行缩放，因此focus权重不等于最终桶概率。1,024更新后的第四次决策只被记录，没有继续训练来消费该分布，不能算作第五个训练阶段。所有训练窗口仍来自train，没有将开发失败场景加入训练，也没有采集corrective data。

当前证据支持“采样机制已实际执行，但这次运行没有获得完整任务收益”。它不支持“BC整体已经达到瓶颈”，也不能单凭这些聚合指标确定失败只来自起步、抓持或后半程中的某一环节。

## 执行有效性与工程恢复

- 首次配对smoke因非确定性数值路径失败；统一两组math SDPA、确定性算法后通过。累计8次smoke更新中4次属于失败尝试，另4次属于成功修复；这些不计入正式A/B的2,048次更新。
- A512第二轮闭环曾因NumPy `bool_`无法序列化退出。修复累计稳定抓持布尔类型后，保留旧失败记录、预算和已完成单元；从评估前checkpoint恢复模型、AdamW、采样器及CPU/CUDA RNG，同seed重试一个未完整保存单元，原尝试仍计费计数。
- A257–512逐步loss没有完整落盘，恢复记录以null表达缺失，不能伪造连续loss曲线。模型、优化器和采样器恢复点已核对；后续恢复点继续保存这些状态。
- 用户随后批准加时完成原A/B批次。A1024最终离线评估期间进行保存后交接，取消训练器与启动器的旧墙钟截止，恢复已完成的训练和前三轮反馈；这次交接未增加闭环episode尝试。
- 实际发布源码对应的云端针对性回归为 **21 passed / 3.88秒**，范围为`test_metric_rules.py`和`test_metric_rollout.py`。其他历史版本的24或70项测试不是本快照重新执行结果。
- 原控制步与288次episode尝试上限始终保留。一次失败重试占用了一个名额，最终保留比较因此少一个单元，未缩小计划分母或追加预算。
