# Front RGB-D → 三维中心 → Object Memory：第一阶段

状态：第一阶段实现与隔离仿真实验完成。有效测量精度有正信号，但覆盖率62.5%未达到预设75%，整体候选目标未通过。见[实验结果](results.md)与[结构化摘要](summary.json)。本轮没有启动VLA训练或闭环操纵。

## 问题与范围

检验解除固定高度后，front RGB-D是否能在已知4cm立方体上给出可信的完整XYZ中心，并通过现有Memory完成三帧提交、遮挡期间保持、到期失效和新Episode清空。先用理想渲染深度/仿真标定建立工程上界，不宣称真实RGB-D精度、任意形状/遮挡下可观测，或D049正式provider资格。

输入是预测红色区域、深度、相机内参与同帧base_from_camera。不得读取GT位姿、GT分割、固定物体高度或场景seed来推断中心。4cm尺寸是明确的物体模型先验。GT只在预测及Memory更新后用于误差和可见性审计。

## 冻结协议

- 24个全新development场景，seeds1400000–1400023。世界中心高度0.05/0.12/0.19/0.26m，两个X位置、三个yaw及预定pitch；这些设置仅用于生成和评估，不进入测量。没有训练或开发集调参后另称独立test。
- 场景是已知尺寸、运动学且无碰撞的静止方块测量夹具，可在不同高度固定；不冒充悬空动态物体或真实操纵。原任务奖励/成功状态不使用。
- front640×480、垂直FOV60°，wrist128×128。FOV在首帧采集前按4cm物体/约0.4–0.7m距离的像素尺寸估算固定，避免只提高分辨率却仍使可见侧面过小；不按评估结果修改。请求rgb+depth+segmentation，但测量仅消费front RGB-D；wrist深度和分割GT不进入测量。厘米/毫米及OpenGL/OpenCV变换由合成测试验证。
- 每场景两个预定front相机位置：(.3,0,.6)、(.3,-.08,.6)，朝向固定世界点(-.1,0,.1)。每位置采3个真实连续tick；相机位置不由GT或结果自适应选择。
- 然后加入黑色遮挡夹具，读一次新观测；固定hold再推进真实时钟，在最后一次可见测量后超过2.5秒再次读。每场景保存8帧，共192帧，其中144帧无额外遮挡、48帧遮挡；机械臂原生遮挡保留，不替换失败场景。
- 机器人只发送固定关节零增量、夹爪打开的hold推进仿真时钟；无VLA、规划/Reach动作、抓取或接触控制。每个控制tick检查实际关节相对reset漂移<0.03rad、TCP漂移<1cm、两指开度合计>6cm，包括没有保存图像的等待tick；终止/截断即停止。Memory safety是已声明的静止无碰撞台架范围，不能移用于操纵中的接触判定。
- 单实例RGB规则R>80且R>2.5G且R>2.5B；若第二大连通域超过第一大30%则拒绝；3×3腐蚀后至少80像素。阈值在本次真实数据生成前冻结，不按GT定位目标。
- 相机深度按光轴Z、毫米输入，转换为米并反投影；有效范围50–2000mm。至少120点、最多确定性抽样2500点。RANSAC每面384次，距离1.2mm，至少40点且占全部点4%；要求三个近正交可见面，法向点向相机。
- 用每个面法向n、平面截距d及已知半边长h求解n·center=d-h。没有三面则明确拒绝，不把点云质心作为物体中心。形状一致性要求90%以上点距拟合立方体表面小于2.5mm。
- 协方差是带2mm几何底噪和1mm标定底噪的启发式候选，confidence固定中性0.5，未经概率校准。新provider身份独立，不使用D049权重、资格或原信息增益阈值；仅允许隔离Memory候选写入和读出。
- 复用ObjectCandidateWindowVerifier、ExplicitObjectStateMemory和12D snapshot：3个独立时间帧、最大间隔75ms、窗口位置差5mm、innovation10mm、最大位置std20mm、TTL2.5秒；来源检查启用。读取快照不等于Action Expert已经消费或获得任务收益。
- 每次切换相机视角清空候选窗口，重新积累三帧，已提交Memory保留并正常计龄；新Episode清空二者。启动前保存全部24个planned场景，执行中记录running/completed/error，失败和未执行分母保留。

## 验收与停止

保存全部场景、frame、测量拒绝和Memory拒绝分母。报告3D误差median/p90、Z绝对误差p90、1cm内占完整分母比例、按高度/视角的覆盖、实际初始化场景、遮挡保持/到期失效。候选目标为可接受测量p90三维误差≤1cm且无额外遮挡帧覆盖≥75%，还须各高度有证据；不通过则报告negative/inconclusive，不事后改阈值。

所有尝试本轮累计最多300GPU进程墙钟秒、200MB新增产物（双副本计入），继续计入此前295.54/900秒及约0.946/2GB累计限制；一次有界工程修复，保留失败与输入身份。不得为提升coverage追加挑选seed或静默放宽三面/一致性条件。若公共测量定义失败，先记录原因，不开展下游训练。
