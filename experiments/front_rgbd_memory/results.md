# Front RGB-D → 三维中心 → Memory：第一阶段结果

2026-09-07。状态：**实验有效完成；精度有正信号，覆盖率不足，整体候选目标未通过。**

24个新development场景、192帧全部执行完成，退出码0。front RGB-D在被接受的已知4cm立方体样本上达到约1.20mm的三维误差p90；144个无额外遮挡帧中仅90帧产生有效测量，覆盖率62.5%，低于运行前固定的75%目标。没有按结果降低门槛、挑选新seed或追加实验。

## 实际接通的数据流

```text
front RGB + 同帧深度、内参、相机相对机器人基座位姿
  → RGB规则提取红色区域
  → 毫米深度转换为米，反投影为基座坐标系点云
  → 三个近正交平面 + 已知4cm尺寸，求完整XYZ中心
  → 独立provider的三帧候选窗口
  → 现有ExplicitObjectStateMemory
  → 12维Memory快照读取、遮挡保持与TTL失效
```

GT物体位姿和GT分割只在本帧测量、Memory更新完成后用于审计，没有作为测量输入。没有输入固定物体高度、桌面高度或场景seed来估计中心。机器人基座位姿与相机标定来自仿真传感器链路；这仍是理想标定条件。

本轮没有加载Qwen或Action Expert，没有训练，也没有根据Memory生成操纵动作。机器人执行固定hold以推进真实仿真时间；相机按预定位置直接设置，未验证机械臂可执行的自主观察动作。

## Memory行为

| 检查 | 结果 | 分母说明 |
|---|---:|---|
| 场景至少一次成功写入 | **18 / 24** | 6个场景从未初始化 |
| 三帧窗口提交 | 30 / 48 | 48个预定场景-视角窗口 |
| 遮挡后仍能读取Memory | **18 / 18** | 只统计此前成功初始化的场景 |
| 超过TTL后快照不可用 | **18 / 18** | 只统计此前成功初始化的场景 |
| 遮挡阶段产生新的有效测量 | **0 / 48帧** | GT审计确认目标可见像素均为0 |
| 切换视角后前两帧提前提交 | **0 / 96帧** | 48个窗口各自前两帧 |

场景至少一次写入18/24=75%，不能替代预定的逐帧测量覆盖率90/144=62.5%。窗口提交30/48也为62.5%，是因为本次成功窗口的三帧均有效，二者并非同一个统计定义。

共读到78个可用快照，这是重复读取次数，不是78次独立定位成功。遮挡测量没有刷新`last_observed_timestamp_s`；最终读取时，距离最后提交已超过2.5秒。6个未初始化场景始终无快照，不能把它们计入“正确保持”或“从有效到过期”的成功数。

新Episode前两帧均无可用Memory，三帧窗口未跨Episode或跨视角拼接。每个控制tick均执行夹爪/关节/TCP检查；已保存帧的关节和TCP漂移均为0，没有台架越界错误。Memory的接触相关前提来自本次静止、无碰撞夹具设计，不能用于证明真实操纵时的接触识别。

## 瓶颈与反例

本轮结果支持：**在满足当前几何可观测条件时，RGB-D能给出精确位置，现有Memory也能保存并读出它；当前主要限制是测量覆盖率。**

当前估计器要求同时观察到三个足够大的面。只有一两个面时，它选择拒绝；RGB-D深度本身并不自动给出完整物体中心。45次三面条件拒绝是本轮最主要的失败类型，但尚未证明这45次全是信息上绝对不可解，也可能包含当前拟合方法和点数门槛的局限。

三个面是本次中心估计方法的限制，Memory接口本身没有面数要求。当前方法只利用平面约束和已知半边长求中心，没有充分利用轮廓、有限面边界或历史视角。不能据此声称“少于三个面必然无法定位”。

连续三帧则是另一个时间稳定性检查：相邻间隔不超过75ms，窗口位置最大差不超过5mm。通过后Memory保存最新一帧的位置和协方差，不对三帧求平均，也不融合两视角点云。本轮30个提供三帧有效测量的窗口全部提交，没有观察到Memory额外拒绝这些完整窗口；主要损失发生在上游测量阶段。缺失或不完整的几何信息保存在实验原始数据中，但没有进入当前Object Memory积累。

第一个视角在14个场景写入，第二个视角在16个场景写入，交集12个。第二个视角补救了4个场景，同时另有2个第一视角可测的场景在第二视角不可测。两个视角都成功的12个场景中，中心估计差异最大0.161mm，仅表示本夹具条件下的一致性。

两个具体事后诊断例子：

- 场景1400000：第一视角找到两个面而拒绝；第二视角找到三个面，随后完成三帧写入。改变视角有机会补足几何信息。
- 场景1400002：两个视角分别有820、900个GT目标可见像素，预测区域纯度均为100%，但都只找到两个面。目标存在且区域提取正确，仍不保证当前中心估计方法可用。

这两个例子用于解释已完成结果，没有用于调整协议或重新评估。下一步值得比较基于已知形状的部分可见拟合，以及以可观测性为依据的重观察；本轮没有验证这些方法，也没有开始新的实验。

## 允许与不允许的结论

已经验证本实验分布中的完整XYZ估计及Memory读写链路，解除固定高度假设有直接正信号。预定目标“p90≤1cm、覆盖率≥75%、各高度有证据”中，精度和各高度证据满足，覆盖率失败，所以整体候选目标未通过。

目前仅支持已知尺寸的红色立方体、预定姿态及理想深度/标定。一般XYZ不等于任意形状、完整6D姿态或任意遮挡可解；毫米级结果不是真实RGB-D传感器精度保证。协方差是未经校准的启发式量，多帧静止重复不能消除系统偏差。本轮没有获得D049正式provider资格，没有证明Action Expert训练收益、任务成功或物理闭环效果。
