## 验证、恢复与归档

云端 targeted tests：**35 passed、1 deselected、1 warning，3.39 s**。排除项是既有 joint-world/TCP 扩展协议测试，不属于本次 TCP/TCP runner。测试进程的默认 Vulkan ICD 查找出现警告；实际运行显式指定 NVIDIA ICD，RGB/depth/segmentation 渲染和六轴 24 步控制 smoke 通过。两个固定教师窗口的新 checkpoint 预测物理值与保存结果完全一致，旧 checkpoint MAE 差约 1e-8。

v1 首条旧轨迹停止后，汇总器误读旧 trace 中不存在的派生 tracking 字段。修复为从 command_q 与 q_after 重算，并恢复这条完整原始轨迹，没有重跑该 episode。v2/v3 的 JSON tuple/list 表示差异造成前置检查误拒绝；统一序列化表示后仍严格逐值比较，不放宽数值容差。v2 未执行新动作，v3 新学生仅执行 warmup、未执行 policy 动作。全部失败尝试保留；v4 复用 1 条、执行其余 31 条，32 条分母无遗漏、无重复。

主 Agent 另行从原始日志重算步序、Reach、最小/最终距离、实际跟踪误差、命令限制及 16 对初态，全部吻合。这是原始证据复核，不是独立 Reviewer PASS。执行源码的 Python 文件 SHA 与工作区对应文件一致；原 182 文件快照未修改。v4 launcher 退出码 0，运行记录耗时 201.545 s，此时间不包含此前环境恢复与失败尝试。
