# Qwen 空间读出：第一阶段结果

日期：2026-09-07。状态：离线 development 已完成；粗定位有正信号，厘米级精确读出不足，是否为 Qwen 自身的信息不足仍不确定。未运行第二阶段控制实验。

## 结论

**这轮不支持“Qwen 没有空间信息”。它能支持目标的粗定位，但当前小读出器未能稳定恢复厘米级位置。** 实际 Adapter 后的读出比原始 Layer12/24 更好，因此也不支持“Adapter 压缩已经把空间信息毁掉”。结果只涉及这次固定相机、红方块、当前 external image span，不外推到完整 Qwen 上下文或一般三维任务。

## 数据和冻结条件

- 新场景 seeds 1300000–1300047，共48个；与已核验的历史176个训练场景无seed重叠。按冻结排列分32个训练场景、16个development场景，每场景在已执行0/8/16/24步时采4帧：128帧训练、64帧评估。统计上的独立development场景数是16，不能把4帧或3个初始化当作更多独立场景。
- 原始双相机图像为128×128，实际processor将每张resize为256×256；external有64个token，即8×8网格。上采样不增加原始画面细节。全部external token进入自主selector，推理时不使用GT选择token。
- 冻结Qwen3.5-2B及当前Layer12的已训练Adapter；实际checkpoint SHA为`a542076f291e29b68e3d28930b15c40396d511a44eb358c2eaeb4e113c041ad6`。Qwen revision、预处理和完整身份见[设计](README.md)及[机器可读摘要](summary.json)。Action Expert与Memory未进入本次计算。
- 三种表示分别用低容量selector/UV头，及按预定触发追加的MLP32头；各3个初始化、400训练步。三组均触发MLP复核，另有3个grid-only头，共21个小读出器。未选择最好初始化或development最优checkpoint。
- GT用于UV/selector监督、误差和可见性审计；无GT裁剪或推理时选token。XY统一用标定与固定world z=0.02m平面求交，未使用逐帧GT高度。
- 192帧中心全部在投影视野内；100帧中心直接可见、24帧部分可见、68帧目标可见像素少于4。development中对应30/11/23帧，全部保留。各组64帧均有有限UV/XY预测。

## 为什么仍不能归因为Qwen缺信息

1. **读出确实依赖正确对应的视觉token。** 未错配的Qwen/Adapter表示条件优于训练位置均值；同phase、不同scene的整组特征错配后明显变差。动作开始前的phase0也有同方向差异，例如Adapter MLP的XY median从3.72cm变成13.65cm。错配不能完全排除机器人姿态、背景等视觉捷径。
2. **粗区域选择已明显优于位置先验。** 事后CPU诊断复用全部已训练头，没有再次拟合。Layer12低容量头的最近目标网格命中分别为57/64、58/64、58/64，均值90.1%；phase0三个初始化均为15/16，即93.75%；训练集多数网格先验在development为24/64，即37.5%。本集合GT实际落在4个网格内，不能把它称为一般64类别或通用目标定位成功。
3. **选对区域之后，连续坐标仍不够准。** Layer12低容量头在各初始化各自的57/58/58个selector正确样本上，XY median分别为5.94/7.04/5.56cm，再取均值为6.18cm；这不是固定64帧总体median。即使用GT直接选择最近网格中心，在固定64帧上误差median也有5.59cm、p90为7.03cm、小于2cm为0/64。这是“只输出格心”的量化误差，**不是token内信息的精度下限**：连续坐标头可能恢复格内偏移，本轮Adapter头也已比格心参考更精细。
4. **小数据泛化也是明显混杂。** Layer12 MLP三个初始化的训练XY median为0.45–0.93cm，development为5.06–5.91cm；因此不能把读出器泛化失败解释成表示根本不含信息。Layer12/24的训练预算、读出结构和32个训练场景仍有限。

允许的结论是：当前链路已有粗定位信号；格内精细定位、读出器的泛化和观测分辨率值得优先检查。未证明唯一瓶颈，未证明提高分辨率必然有效，未验证这些坐标足以支持闭环控制或Memory测量写入。

## 执行、修复和证据

- 采集34.50秒；首次特征提取47.81秒；身份修复后的重新提取54.13秒；21个读出器训练26.60秒。均退出0。本次累计GPU进程墙钟163.04秒，连同此前两实验为295.54/900秒。事后selector分析使用CPU，不新增训练。
- 首版缓存未被训练消费：独立审查发现按数组位置配对缺少强制身份校验。补充manifest SHA、有序sample IDs、RGB身份和shape/finite校验后，保留首版并重新提取。两个版本的三组特征张量逐元素完全相同，修复改变身份约束，不改变数值。
- 主实验源码快照为`source-manifest-v2.json`；后增的`inspect_readout.py`明确属于事后诊断，不追认为预注册条件。该诊断的首版与增加多数网格先验/正确选择子集分析的第二版均保留。
- 远端CPU针对性测试：7 passed，exit0，覆盖同长度清单重排、哈希变化、NaN、训练归一化隔离、无GT推理、固定平面及缺失预测分母。独立审查实际模型为Sol/high，采集、身份修复和最终数值汇总分别取得限定PASS；最终复核要求明确事后子集分母及替换一处易混淆的“原图”表述，已修正，无需重跑。
- 私有实验产物已完成双副本校验：378个文件逐项SHA256/大小一致，单份受校验产物约261MB；本次双份产物连同此前两实验累计约0.95GB，低于2GB上限。公开版本仅包含实验源码、测试、设计、脱敏报告及聚合指标，不包含图像、逐帧GT、权重、缓存或原始日志；未修改稳定`src/`。

下一步优先建立可靠的图像定位参考，并以新协议比较“识别目标区域→显式网格坐标＋格内偏移”与当前直接回归。若比较图像分辨率，应改变真实相机采样并冻结相同场景与预算；仅放大128×128图像不足以检验新增视觉细节。待离线定位足够可信，再把坐标接入同一个显式Reach控制器做第二阶段比较。
