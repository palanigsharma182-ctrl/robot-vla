# Qwen 空间信息读取诊断：实验设计

状态：第一步离线development已完成，见[结果与限制](results.md)及[完整候选摘要](summary.json)。第二步控制实验未运行。

## 要回答的问题

在当前固定相机、桌面红方块 Reach 场景中，冻结 Qwen 的特征是否包含可由小型读出器利用的目标位置信息？若效果不足，问题更接近目标选择、坐标精度、层选择、Adapter 压缩，还是下游没有利用已有信息？

本轮绕开 Action Expert。探针失败只能说明在指定读出器、数据和预算下未读出信息，不能证明信息不存在。Layer12优于Layer24只能说明更容易被该读出器利用，不等于深层信息不可恢复地丢失。

## 现有代码与旧证据的边界

- `src/robot_vla/diagnostics/qwen_spatial_probe.py` 的旧线性探针使用GT坐标选择目标token，仅作为“已知目标区域”的条件诊断；不作为自主定位能力的主要证据。
- `src/robot_vla/diagnostics/v2_online_geometry_probe.py` 已有全token目标selector和连续UV读出器，可复用其中不依赖V2数据结构的部分。
- 不把旧V1缺失的时间/位姿字段补零后伪装成V2。使用当前待诊断路径实际消费的图像与prompt格式，并在实施前固定checkpoint、层和Adapter身份。
- `QwenVLAAdapter` 将2048维token映射到720维，因而应检查实际已训练Adapter的输出；随机新建Adapter不代表当前系统。

## 第一步：小规模离线定位

建议先用48个独立场景，每场景最多4个预定Reach阶段画面，约192个不重复样本。32个场景用于训练小型读出器，16个用于development诊断；按场景整体划分，避免相邻帧跨集合。场景覆盖工作区，不只在同一个位置附近重复采样。所有数字为实施前建议，需在运行记录中冻结。

已有数据优先，但必须满足图像、当前物体GT、对应标定可核验。若需要补采，只补必要场景。历史受保护test不重用；development结果不称最终独立验证。

先固定相机与物体类别，只测当前帧目标定位；RGB输入、分辨率、裁剪、prompt、目标身份、标定和数据划分在各组保持一致。Qwen与已有Adapter全部冻结，只训练低容量读出器；一次前向缓存各层特征。第一轮不训练Qwen，不增加Memory或动作学习变量。

| 条件 | 输入与读取 | 用途 |
|---|---|---|
| 图像定位参考 | 同有效分辨率RGB的简单颜色/轮廓定位 | 检查该简单场景是否有直接可利用的视觉线索；不是通用视觉能力上界 |
| Layer12 | 全部相关visual tokens，自主selector + UV读出 | 检查中层目标定位能力 |
| Layer24 | 相同读出器、初始化与训练预算 | 检查层选择对可读信息的影响 |
| 当前Adapter后 | 实际消费层经过已训练Adapter的token | 检查消费者入口；输入维度不同，报告参数量，不假装严格同容量消融 |
| 无图像基线 | 训练集平均位置／仅网格中心、固定上下文 | 检查位置先验或坐标布局能达到什么水平 |
| 图像错配检查 | 固定development样本标签，打乱不同场景的图像/token内容与标签对应 | 检查读出是否依赖视觉；保持网格/文本/proprio等非图像因素可比 |

GT可用于训练监督、误差计算和预先声明的可见性分层；不得进入推理时的token选择、裁剪、坐标输入、prompt或几何转换。图像错配是在development上的诊断，不用来修改该集合标签再训练。

主评估使用全token自主定位；旧GT选token探针可作为独立标记的辅助诊断。后者如果表现好、全token读出差，提示目标选择/关联问题，不能把GT辅助结果当可部署定位结果。

## 指标与防止错误归因

- 先评价归一化UV和像素误差：median、p90、完整样本数与独立场景数；不通过重复采样扩大分母。
- 在固定相机和预先规定的桌面物体中心高度假设下，可用同一标定转换为base-frame XY误差；不能读取逐帧GT z完成反投影。二维定位好不等于三维测量好。
- 报告位置误差低于1cm、2cm、4cm的比例；这是几何精度诊断，不是新的正式Reach或部署门槛。
- 将可见、遮挡、出视野情况按固定规则分开报告，同时保留完整分母；不把projected等同observable，也不删掉困难场景。
- 分场景报告误差，定位偏差随目标位置或机器人姿态的变化；控制相机/机器人状态与目标位置的捷径相关性。
- Layer12/24用匹配结构和预算；Adapter后输入维度不同时明确容量限制。若初次低容量读出失败，允许一个预先规定的小MLP作有界复核；MLP恢复精度说明线性可读性不足，不能称空间信息不存在。
- 小读出器可使用3个初始化seed检查偶然性；只用train统计做归一化，不用development标签拟合转换或挑特征。

## 第二步：固定显式控制器，验证空间误差是否影响任务

第一步出现可解释信号后，再冻结读出器，分别将GT坐标、RGB定位参考坐标、Qwen读出坐标送入已验证的同一个显式Reach控制器。使用新的配对development场景和共同100步上限；固定夹爪、姿态约束、反馈频率与无效输入处理，不经过Action Expert。

这一步区分“离线能读出位置”与“在线精度/时序足以控制”。若当前阶段只恢复了桌面XY，明确固定高度假设，不宣称一般三维或接触任务能力。GT只属于Oracle对照，不用于修补其他条件的缺失输入。

## 结果解释

| 观察 | 可支持的判断 |
|---|---|
| Layer12好、Layer24差 | 当前读出条件下中层更适合定位 |
| Adapter前好、后差 | 优先排查Adapter与读取能力的组合，尚不能断言不可逆信息丢失 |
| GT选token好、自主选择差 | 优先排查目标选择/关联 |
| 低容量探针差，小MLP好 | 信息可以被读出，但不是足够简单的映射 |
| RGB定位好，各Qwen探针差 | Qwen输入处理、特征或读取链值得排查；尚不能仅归因backbone |
| 图像错配后指标几乎不变 | 警惕位置先验、数据捷径或泄漏，不能宣称视觉定位成功 |
| Qwen坐标接显式控制表现好，原学习动作差 | 更支持下游动作策略没有有效利用空间信息 |
| 连RGB参考也差 | 先排查图像可见性、预处理、标定及参考算法，不能据此证明图像无信息 |

执行建议：先只完成第一步，缓存一次Qwen特征；不直接开始完整VLA训练。实施前测算实际token数、缓存大小和一次前向耗时，再把采集、特征提取与小读出器训练纳入同一个明确资源上限。阶段二不因阶段一结束而自动启动。

## 本次冻结实施参数

- 48个全新scene seeds 1300000–1300047，NumPy default_rng(20260907)固定排列前32个train、后16个development；每scene在实际执行0/8/16/24步时采样。场景整体划分，训练过的历史D0不作为本轮样本。
- 相机固定；全体中心必须projected-in-view，否则保存全部已采记录后停止为protocol-invalid，不夹紧或删标签。分层：出视野、可见像素少于4的遮挡、中心像素属于方块、其余部分可见。分割只审计。
- 固定当前V1双图prompt；Qwen3.5-2B revision 15852e8c16360a2fea060d615a32b45270f8a8fc；实际Layer12 Adapter checkpoint SHA a542076f291e29b68e3d28930b15c40396d511a44eb358c2eaeb4e113c041ad6，history_length=1、strict load、eval/no_grad、BF16 autocast。
- 缓存真实external image span的全部token，三条件使用同一mask/顺序。没有读取wrist/text位置的hidden state；负结果不能外推到完整Qwen上下文。GT不参与特征选择，训练loss含GT UV和nearest-token selector监督。
- 低容量头：Linear selector + softmax pooling + Linear UV/sigmoid；train-only每维z-score，std下限1e-4；初始化42/43/44，每个400steps、batch32、Adam lr1e-3、selector CE权重0.1、梯度裁剪1，保留最后一步而不按development挑checkpoint。记录所有初始化和参数量。
- 对每个视觉表示，若三个低容量头的development XY median均值超过2cm，追加32维Linear/SiLU投影后同类头复核；相同3初始化和400steps。此触发属于预定development诊断，不是独立confirmation；grid-only不追加MLP。
- RGB按Qwen实际resize后图像，用R>80且R>1.4G且R>1.4B区域质心，少于4像素明确缺失；不看GT再调阈值。
- 错配固定按development scene ID排序循环替换，phase不变、标签和标定不变；单独报告phase0，不能仅凭错配退化排除机器人姿态等视觉捷径。
- UV为主读出指标，XY统一射线与world z=0.02m求交，不读逐帧GT z；完整分母、invalid、phase/visibility/scene分层。
- 第一阶段本次累计最多760 GPU进程墙钟秒，与前两实验132.501秒共享900秒总上限；新增磁盘与既有约423MB共享2GB，不扩充Qwen、Memory或控制实验。超过预算保留已完成与失败记录，停止而非追加种子。
