# Align 显式相对位姿输入：最小离线 BC 对照

用户在暂停并准备释放 GPU 的备份期间，追加本项小实验。已有全量备份照常进行，本实验输出使用独立 scratch 目录，完成后单独回传。自动训练监控保持暂停。

问题：在冻结 Qwen context 与 proprio 之外，给 Action Expert 提供明确的目标相对位姿，能否改善 Align 动作预测？

- A：Qwen context + proprio；新增误差投影输入固定六个零。
- B：相同输入 + 当前 TCP 轴向中的三维位置误差、三维旋转向量误差，分别除以 0.05 m、0.5 rad。固定目标来自教师 `world_from_pregrasp`，当前位姿由当前观测关节角做 FK；不读取未来动作构造输入。
- 两组均从原 Align BC512 checkpoint 出发。将原状态编码器第一层保留为一条投影，再相加一个无 bias、零初始化的 6 维误差投影。结构及参数数目相同，初始新增分支贡献为零；A 的新增权重梯度始终为零。稳定 src 与原 checkpoint 格式不改变。
- Qwen、adapter、memory encoder 冻结，原 memory 不可用；两组只更新 Expert，AdamW 重置、lr=1e-5。各 64 次更新、每次累积 4 个窗口；相同采样与 flow 噪声种子 1950042。纯 BC，不新增 DAgger。
- 训练取前八个合格 train 场景，每场景均匀八个 Align 锚点。离线评估取前八个 val/development 场景，每场景均匀三个锚点；事先固定，不根据表现选择。开发集与本次训练场景分离，但历史模型曾用该 development 集分析/选择，因此不称独立 final test。
- 主指标：有效前四个动作与教师平移动作的平均误差（mm）。另记旋转动作误差、夹爪 MAE、首动作使目标距离增加的比例。推理使用完整 16 步 mask 与十步 Euler，评分只覆盖本技能有效标签。
- 共同起点只评估一次。训练后分别评估 A、B，并对 B 将误差置零再评估，检查新增输入是否被实际使用。固定最后一步权重，不按开发集选 checkpoint。
- 总运行上限约 15 分钟，单 GPU 串行两组；遇到非有限数值、缓存缺失或来源不符停止。首次启动因工作目录错误在源码校验阶段失败，未训练；保留原记录，修正启动目录后再运行。

这里使用 privileged 教师目标，只能诊断显式几何输入是否有帮助，不能声称视觉系统能提供相同精度，也不修改部署输入合同。本实验仅使用教师分布下的离线状态，既不证明学生独立闭环成功率，也不证明 DAgger 偏离状态上的恢复能力。小预算负结果也不能排除该路线。

`run.py` 保存配置、精确索引、采样序列、sidecar 哈希、特征、逐场景指标和两个探索权重。权重不包含优化器，不能当作精确续训恢复点。`test_run.py` 验证零初始化等价、A 分支梯度为零、B 分支梯度有效及旋转坐标往返；测试在云端执行。
