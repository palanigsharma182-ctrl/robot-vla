# 七个独立技能策略的 BC + DAgger 训练方案

记录日期：2026-09-09。架构见 [七个独立技能策略与上层调度](hierarchical_policy_plan.md)。本文件区分已启动的 BC 配置与尚待验证的 DAgger 设计；不是收敛或完整任务验收报告。

后续更新：独立 BC、首轮 DAgger、Align 第二轮及 Transport/Lower 原示范覆盖对照均已有完成结果，见 [最新结果](../seven_skill_dagger/results.md) 与 [实现入口](../seven_skill_dagger/README.md)。以下状态和候选参数保留首次发布时的方案快照，不代表当前仍在等待实现；末尾训练场景勘误适用。

## 目标与首次发布时状态

分别训练 Approach、Align、Grasp、Lift、Transport、Lower、Release 七个独立策略，完成各自标准入口、合法扰动及真实交接验收后，保留七个策略，由上层选择和切换，完成 Pick→Carry→Place。七份 Expert 不做权重平均或统一学生蒸馏。

截至本次发布前最近一次运行核验：首轮独立 BC 已启动，Approach 与 Align 各完成 416/512 次更新，其余技能由两路队列接续；尚无本轮收敛结论。自动运行脚本覆盖七技能 BC 和随后各自的标准入口开发评估。**新独立策略的 DAgger 尚未开始训练**，纠偏数据读取、跨轮聚合和训练接入仍需补齐并验证。

旧共享学生已经完成过一轮接管式 DAgger，结果见 [首轮结果](results.md)。该结果不代表新独立策略已经做过 DAgger，也不改变本阶段的数据身份。

## BC：学习完整的单技能过程

| 项目 | 首批实际配置 |
|---|---|
| 模型 | 七份独立可训练 Expert，各自优化器与 checkpoint |
| 初始化 | 旧首轮 BC 最终权重；SHA256：`c0059309aa4a2dc90f1c498f8716227adc04f888193c72900fb0cb8428a3efea` |
| 优化状态 | 各自重置 AdamW，不继承旧共享学生的优化状态 |
| 训练数据 | 现有已审计七技能教师 train 数据，128 个计划场景中 124 个合格；每策略只采样对应技能 |
| 学生输入 | 外部图像、腕部图像、15 维本体状态、任务指令；不输入物体位姿或技能 GT |
| 冻结部分 | Qwen、adapter、memory encoder；复用冻结特征缓存，Memory 保持 masked |
| 动作 | 长度 16 的 TCP chunk，每步 3 维平移、3 维旋转和 1 维夹爪命令 |
| 监督边界 | 截止于当前技能第一次出口，包含完成出口的动作；之后的目标置零并 mask |
| 损失 | 沿用 masked flow-matching loss，在教师动作 chunk 上做监督学习 |
| 优化参数 | AdamW，学习率 `1e-5`，BF16，每更新累计 4 个窗口，梯度裁剪范数 1 |
| 采样 | 本技能桶内打乱、无放回遍历，走完再重新打乱 |
| 首轮长度 | 每技能 512 次更新，共 3,584 次独立优化更新 |
| 保存与选择 | 每 128 次保存；固定最终 512 次 checkpoint，结束严格重载，不按开发结果选中途最好权重 |
| 并行 | 两个独立进程并行，其他技能排队；以显存与实际吞吐决定并发 |

每技能 512×4＝2,048 次窗口曝光，可能重复使用窗口，不是 2,048 条新轨迹，也不保证全桶覆盖。512 次是首轮检查点，不是稳定收敛标准。

Grasp 的训练覆盖从其入口到完成抓持的整个过程；Lift 的训练覆盖建立抬升到满足抬升出口的过程。若 Grasp 的一个动作 chunk 跨到 Lift，只有仍属于 Grasp 的部分参与监督。尾部仅剩 1 个真实动作时仍保留，不补造未来动作；原有全任务标签保持只读。

执行维持 20 Hz，每次最多执行前 4 步后重新观察规划，技能完成时立即结束旧 chunk。短跑与正式训练使用不同输出，短跑更新不计入正式 512 次。

## BC 后的开发评估

每个策略完成首轮 BC 后，自动在 1811000–1811007 这 8 个 development 场景分别验证，共 56 个单技能单元。教师只准备目标技能的合法标准入口，随后学生独立执行，最多 160 个动作。

主要报告各技能成功数/计划数，以及入口准备失败、技能不变量违反、抓持丢失、执行约束失败、超时和实际动作数。所有失败保留在完整计划分母中；有条件的有效入口成功率如需补充，单独列出其分母。训练 loss 用于观察优化过程，不能替代真实闭环成功率。

这些是可反复使用的开发场景，不是独立最终 test。8 场景标准入口结果不足以认证扰动容错、真实交接或稳定收敛。

## DAgger：从学生实际访问的状态学习纠偏

采用接管式 DAgger：先让当前学生执行，在指定时刻由教师从当前真实状态接管，采集恢复轨迹，再与既有示范聚合训练。它是经典 DAgger 的变体：经典形式通常查询学生访问状态上的教师动作；本方案还采集教师接管后完成当前技能的连续恢复段。

每个技能独立迭代以下步骤：

1. **学生 rollout。** 只从 train 场景准备技能入口，让该技能当前学生实际执行。保留其造成的位置、姿态、速度和抓持变化。
2. **真实接管。** 教师从当前状态重新规划；不重置机器人或物体、不回填理想状态。持物恢复保持闭爪，并根据真实 TCP–object 偏置确定目标。
3. **标签审计。** 核验接管前后图像与 proprio 一致、命令参考连续、时间与动作对齐。学生前缀仅用于诊断；训练监督只来自接管后的真实教师动作，止于本技能出口，允许尾部不足 4 步。
4. **数据聚合。** 每个技能维护自己的纠偏桶，保留原始示范和各轮合格纠偏样本，避免遗忘标准执行。开发评估轨迹不进入训练。
5. **继续监督训练。** 从该技能上一轮候选初始化，用混合数据继续优化相同动作生成目标；每轮保存独立配置、来源和 checkpoint 身份。
6. **重新验证。** 用更新后的学生检查独立闭环成功率和失败类型；追加轮次时重新采集该学生访问的状态，并记录累计数据曝光。

教师能恢复只说明该接管位置能产生纠偏监督；学生更新后的独立成功率提高，才说明学生学会了纠偏。

### 起步参数：候选设计，尚未全部冻结或运行

| 环节 | 候选设置 |
|---|---|
| 小规模接管检查 | 每技能 2 个训练场景，分别在约 25%、50%、75% 技能进度尝试接管，七技能共 42 个计划单元 |
| 后续扩采 | 每技能每轮最多 8 个训练场景 × 3 个接管进度 |
| 进度定义 | 基于距离、抬升高度、夹爪等连续指标的采集启发式；不是固定时间百分比，也不替代技能完成判据 |
| 单元长度 | 学生最多 160 步，教师恢复最多 160 步；入口准备计入实际控制预算 |
| 混合采样 | 原示范 : 累计合格纠偏窗口先取 3:1；每次累计 4 窗口时对应 3 个原示范和 1 个纠偏窗口 |
| 每轮更新 | 每技能最多 512 次，之后进行开发闭环评估 |
| 对照建议 | 比较同一起点的继续 BC 与混合纠偏训练，匹配更新数及场景；未运行对照时不将改善全部归因于 DAgger |

正式启动前还须固定：接管小实验放行数值、故障状态处理、是否设置等更新数 BC 对照、跨轮优化器/RNG 继承、数据去重和累计范围、追加/停止规则及总资源边界。这里的候选参数不表示这些实现已经存在或通过验证。

当前采集草稿主要在进度点或超时处接管；若学生提前丢失抓持、违反技能不变量或遇到执行约束失败，会记录失败，未必能够产生合格监督。小实验必须检查这种筛选是否漏掉主要失败状态，不能仅凭容易恢复的样本宣称覆盖了真实失败分布。无候选、不可恢复和标签无效分别统计，不反复换场景直到成功。

## 单技能验收与后续联合

最终需要依次验证标准入口、合法位置/姿态/速度/持物变化下的容错，以及六个相邻技能的真实学生交接。计划扩到 32 场景的标准入口检查，扰动覆盖和数值通过门槛须在使用前固定；本文件不把此前候选阈值追认为已采用标准。

交接保持真实环境、命令参考和抓持连续，旧技能剩余 chunk 作废，新技能读取最新观测。更新某个下层策略后，重验该技能及受影响交接；最后完整任务结果绑定完整的七策略集合身份。

全部通过后才推进完整 Pick→Carry→Place。上层起步按固定技能顺序和完成证据切换。仿真 GT 触发的切换只属于 **oracle 调度诊断**；可部署或学到的上层必须从允许观测获取完成证据，并单独测提前切换、延后切换和错误选择。

## 已有证据与执行边界

- 云端针对性测试：新标签/采样 3 项、原训练回归 5 项，共 8 项通过。
- 标准入口教师恢复 pilot：同一个开发场景七技能各一次，7/7 通过；不证明学生偏离后的恢复范围。
- 两路训练短跑：Approach、Lift 各完成 2 次更新、保存和严格重载；不属于正式训练或收敛证据。
- 新七策略 BC 已启动；新独立策略 DAgger、扰动全量验收、学生真实交接和上层联合尚无完成证据。

本次发布为方案文档，训练实现尚未随本次提交公开。运行使用隔离源码快照和输出；训练、仿真和测试在云端，现有冻结结果保持只读。BC 单作业 4 小时上限，开发评估每技能 2 小时/12,000 总控制步上限；这些是工程停止边界，不是预估耗时或收敛标准。
